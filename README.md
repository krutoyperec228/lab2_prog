# VIN Validator

Проверка и поиск идентификационных номеров транспортных средств (VIN)
по стандарту ISO 3779. Проект использует `uv` для управления
зависимостями и виртуальным окружением.

## Возможности

- Проверка формата VIN (17 символов, допустимые символы, позиция 9).
- Полная проверка с контрольной цифрой (алгоритм ISO 3779).
- Поиск VIN в произвольном тексте, файле или на веб-странице.
- CLI с тремя режимами: ручной ввод, URL, файл.

## Требования

- Python 3.10+
- [uv](https://docs.astral.sh/uv/)

## Установка

    git clone <repo-url> vin_project
    cd vin_project
    uv sync

`uv sync` создаст `.venv`, установит `requests` и `pytest`
(из группы `dev`) и сгенерирует `uv.lock`.

## Использование

### CLI

    uv run python cli.py

Меню:

1. Проверить один VIN (ручной ввод).
2. Найти VIN на веб-странице (URL).
3. Найти VIN в файле.

### Как библиотека

    from vin import is_valid_format, is_valid_with_checksum, find_vins_in_text

    is_valid_format("1HGCM82633A004352")        # True
    is_valid_with_checksum("1HGCM82633A004352") # True
    find_vins_in_text("VIN: 1HGCM82633A004352") # ['1HGCM82633A004352']

## Тесты

    uv run pytest

Покрыты модули `vin/constants.py`, `vin/validator.py`,
`vin/extractor.py`. CLI проверяется вручную (8 сценариев),
так как не содержит собственной логики — только оркестрацию I/O
над уже протестированными функциями.

## Зависимости

Основные:

- `requests` — загрузка веб-страниц по URL.

Для разработки:

- `pytest` — запуск тестов.

Добавление новых зависимостей:

    uv add <package>          # основная

## Ограничения

- Контрольная цифра проверяется по алгоритму ISO 3779; для VIN,
  выпущенных не по этому стандарту (например, некоторые moto-VIN),
  возможны ложные срабатывания.
- Поиск в тексте находит только «структурно валидные» VIN;
  контрольная сумма для каждого найденного проверяется отдельно
  через `is_valid_with_checksum`.
